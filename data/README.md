# KinoCompass – данные

Набор оценок фильмов **MovieLens 32M** и каталог фильмов для сайта и моделей: названия на трёх языках
и постеры. Всё запускается в Docker, нужен только Docker и make.

```bash
make download   # скачать архив MovieLens 32M (239 МБ) с проверкой md5 и распаковать -> raw/
make parquet    # CSV -> work/*.parquet с компактными типами (для исследования и моделей)
make catalog    # каталог фильмов минимум с 20 оценками -> catalog/movies.csv
make titles     # названия ru/kk/en из Wikidata -> catalog/titles.csv
make posters    # пути постеров TMDb -> catalog/posters.csv (ключ TMDB_TOKEN в KinoCompass/.env)
make check      # проверить всё: сверка с README набора, шкала, даты, дубли, каталог
make data       # всё по порядку с нуля
make test       # pytest без сети
```

`titles` и `posters` дозапрашивают только фильмы, которых ещё нет в файле, и сохраняются по ходу –
загрузку можно прервать и продолжить; `python -m collect titles --refresh` запрашивает всё заново.

## Что где лежит

| Папка | Что | В git |
|---|---|---|
| `raw/` | архив `ml-32m.zip` и распакованные CSV (около 1 ГБ) | нет – скачивается `make download` |
| `work/` | `ratings`, `tags`, `movies`, `links` в parquet (220 МБ) | нет – собирается `make parquet` |
| `catalog/` | каталог, названия, постеры и README набора с условиями лицензии (5 МБ) | да |

Таблицы в `work/`: имена колонок `user_id`, `movie_id`, `rating`, `time` (метка UTC), `tag`, `title`,
`genres`, `imdb_id`, `tmdb_id`; `user_id` и `movie_id` – int32, оценка – float32. Оценки весят в памяти
около 0,5 ГБ вместо 1 ГБ в обычных типах.

`make check` сверяет числа с README набора, шкалу оценок, даты, отсутствие повторных оценок одной пары
«пользователь – фильм» и то, что все оценённые фильмы есть в списке.

## Каталог фильмов

В каталог попадают фильмы минимум с **20 оценками**: **23 349 фильмов**, на них приходится **99 %**
всех оценок. У фильмов с единичными оценками нет ни надёжной средней, ни соседей для рекомендаций.

`catalog/movies.csv`:

| Колонка | Что |
|---|---|
| `movie_id` | id фильма в MovieLens |
| `title`, `year` | название и год: из «Matrix, The (1999)» -> «The Matrix», 1999; второе название в скобках убирается |
| `genres` | жанры через «\|» (19 жанров MovieLens) |
| `tags` | до 10 самых частых тегов через «\|» – только те, что поставили хотя бы 2 разных человека (62 % фильмов) |
| `n_ratings`, `mean_rating` | число оценок и средняя оценка за весь период |
| `first_rated`, `last_rated` | даты первой и последней оценки (для анализа «холодных» фильмов) |
| `imdb_id`, `tmdb_id` | ссылки на IMDb и TMDb |

`catalog/titles.csv` – названия из Wikidata по IMDb id: `wikidata` (Q-номер), `title_ru`, `title_kk`,
`title_en`. Пометки вида «(фильм)», «(фильм, 2019)», «(1995 film)» убираются. Найдено 23 038 фильмов
(99 %); русское название есть у 17 326 (74 %), казахское – только у 708 (3 %), английское – у 22 998 (98 %).
На сайте название показывается на языке интерфейса, а если перевода нет – на английском.

`catalog/posters.csv` – путь к постеру в TMDb (`/abc.jpg`); сам постер сайт берёт с сервера TMDb,
картинки в репозиторий не скачиваются. Постер есть у **23 027 фильмов (99 %)**: у 19 фильмов в MovieLens
нет ссылки на TMDb, у 303 в TMDb нет постера или фильм там удалён. Загрузка – 8 параллельных запросов,
около 17 минут.

Особенности набора: у 74 фильмов каталога в MovieLens нет года в названии (например, «Ready Player One»);
один фильм вместо названия имеет только « (2019)» – он в каталог не входит, но его оценки остаются в
данных для моделей.

## Тесты

`make test` – 42 теста без сети: разбор названий, жанров и тегов, сборка каталога, проверки данных,
повторы HTTP, скачивание с проверкой md5, кэш названий и постеров, запросы к Wikidata и TMDb
(на подставных ответах).
