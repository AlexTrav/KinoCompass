# KinoCompass

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Рубежное задание РК-2 по курсу «Искусственный интеллект и машинное обучение»: рекомендательная
система фильмов на данных MovieLens 32M – подбирает фильмы под вкус по 5–10 оценкам и объясняет,
почему именно эти. Сравниваются базовые модели, коллаборативная фильтрация, матричная факторизация,
контентная модель и нейросеть Mult-VAE.

Автор: **Алексей Нерезов**.

> Проект в работе.

## Что уже сделано

- данные: MovieLens 32M скачивается в память при каждом запуске (на диске не хранится), каталог из
  23 349 фильмов (99 % оценок) с названиями на русском, казахском и английском из Wikidata, постерами и
  описаниями сюжета TMDb, проверка данных – [data/](data/README.md);
- исследование данных: длинный хвост популярности, поведение новичков (59 % людей не возвращаются после
  первых суток – главный сценарий холодный старт), связь оценки с популярностью и годом выпуска, жанры и
  корреляции вкусов, теги, годовые окна для разбиения по времени, 15 рисунков – [research/](research/README.md);
- честная проверка рекомендаций: разбиение по времени (обучение до 14.10.2021, валидация – год, тест –
  последний год), сценарии «новичок с 5 и 10 оценками» и «постоянный», метрики точности, покрытия,
  новизны и разнообразия, тесты значимости; базовые модели – лучшая «популярные за последний год»
  (NDCG@10 = 0,345 для новичка с 5 оценками); соседи – user-kNN вровень с ней у новичков и на 13 % лучше
  у постоянных, item-kNN хуже; матричная факторизация – ALS на 10 % лучше популярности у постоянных, но
  хуже у новичков, SVD предсказывает звёзды постоянному на 7 % точнее; лучшая модель шага – EASE (Colab, GPU):
  на 22 % лучше популярности у постоянных и на 2 % у новичка с 10 оценками; контентная модель (TF-IDF и e5 по
  тегам и описаниям) в 2,7 раза слабее популярности, а на новинках уступает простому «сначала самые новые»;
  поиск словами на e5 находит по русским запросам 5 фильмов из 5, по казахским – 1 из 5 –
  [model/](model/README.md).

## Запуск

Нужен только Docker и make:

```bash
make data      # скачать MovieLens 32M в память, собрать каталог фильмов с названиями и постерами, проверить
make check     # проверить данные и каталог
make eda       # исследование: сводки и тесты -> research/results
make figures   # рисунки исследования и моделей
make baselines # базовые модели на валидации -> model/reports
make knn       # соседи (item-kNN и user-kNN) на валидации -> model/reports
make factorization # матричная факторизация (ALS, BPR, SVD) на валидации -> model/reports
make content   # контентная модель (TF-IDF, e5) на кандидатах и новинках -> model/reports
make search    # поиск словами: 30 запросов на ru, kk, en -> model/reports
make test      # автотесты
```

Для постеров и описаний нужен ключ TMDb: `TMDB_TOKEN=<Ключ доступа к API>` в файле `.env` в корне проекта
(в git не попадает).

## Структура

```
KinoCompass/
  data/      – загрузка MovieLens в память и каталог фильмов (catalog/ – в git)
  research/  – исследование данных: сводки (results/ – в git), рисунки для отчёта
  model/     – протокол проверки, метрики, модели, отчёты с результатами (reports/ – в git)
  Makefile   – общие команды
```
