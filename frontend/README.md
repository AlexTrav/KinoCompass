# frontend – сайт KinoCompass

**https://alextrav.github.io/KinoCompass/** – Vue 3, TypeScript, Tailwind CSS 4, vue-i18n (ru/kk/en),
Apache ECharts, lucide. Данные – API [backend/](../backend/README.md) на Render; базы нет, оценки человека
хранятся только в его браузере (localStorage).

## Страницы

| Страница | Что на ней |
|---|---|
| Подобрать (`/`) | оценка фильмов звёздами с половинками, поиск по названию и по описанию (e5), компас вкуса, готовые вкусы в один клик (фантастика, мультфильмы, классика, ужасы; свои оценки можно вернуть), «Поделиться» – ссылка с оценками и QR-код, советы «популярность × ALS» с «потому что вам понравились…», окном «Почему этот фильм», панелью «Почему такие советы» и ползунком новизны, новинки 2022–2023 с «похож описанием на…»; «Показать ещё» листает до конца списка |
| Фильм (`/film/:id`) | постер, названия на трёх языках, описание, ссылки IMDb и TMDb, «с этим фильмом смотрят» (ALS) и «похожие по описанию» (e5) |
| Сравнение моделей (`/compare`) | советы четырёх моделей на ваших оценках вживую; итоговый тест: валидация против теста по 10 моделям, сценарии с переключателем метрик – точность (NDCG@10 с 95 % интервалами), попадание (Hit@10), новизна, покрытие каталога, – честный блок про новинки |
| Карта вкусов (`/map`) | 5000 фильмов (t-SNE по векторам ALS), цвет – сторона компаса, ваши фильмы и ваша точка |
| Исследование (`/research`) | длинный хвост, новички первого дня, оценки, годы, популярность и оценка, поиск на трёх языках |
| Производительность (`/perf`) | живые замеры сервера (`/api/perf`): время каждой точки, память против 512 МБ, ответ до браузера, холодный старт |
| О проекте (`/about`) | данные и лицензии, протокол, модели, честные ограничения, научный руководитель |

У неочевидных мест – подсказки «?» короткими простыми словами.

**Компас вкуса** (`src/utils/compass.ts`): 8 групп жанров MovieLens («Боевики и приключения», «Фантастика и
фэнтези», «Мультфильмы и семейные», «Триллеры и детективы», комедии, мелодрамы, драмы, ужасы). Каждый
оценённый фильм добавляет своим группам вес (оценка − 2,5) · log(1 / доля группы в каталоге): редкий жанр
говорит о вкусе больше частого (драма – у 52 % фильмов, ужасы – у 11 %). Стрелка указывает на самую сильную
группу, закрашенная фигура – сила всех групп.

**«Поделиться»** (`src/utils/share.ts`): оценки записываются прямо в адрес – `/?r=2571-10.318-9` (id и
полузвёзды), сервер их не хранит. По ссылке сайт загружает карточки фильмов, заменяет оценки (свои можно
вернуть) и убирает параметр из адреса. QR-код рисует библиотека `uqr` (без зависимостей) – чёрный на белом,
чтобы его читала любая камера. Готовые вкусы – `src/data/personas.json` (по 7 фильмов, названия на трёх языках
из API); тест проверяет, что компас каждого профиля указывает на его жанр.

**Цифры страниц** «Сравнение моделей» и «Исследование» – `src/data/site.json`, его собирает
[model/site_data.py](../model/site_data.py) из отчётов проверки и исследования; тест `site.spec.ts`
проверяет, что выводы на страницах совпадают с отчётами.

## Запуск и проверка

```bash
make -C frontend test   # 28 тестов Vitest: переводы (одинаковые ключи, без «@» и «|»), компас, оценки, объяснения, ссылка «Поделиться», готовые вкусы, site.json
make -C frontend run    # собранный сайт на http://localhost:8080 (API – Render)
make -C frontend run API=http://localhost:8000   # вместе с make -C backend run – API локально
make -C frontend dev    # dev-сервер Vite на http://localhost:5173
```

Всё – в Docker, локальный `node_modules` не нужен. Тесты, проверка типов и сборка идут в CI
([ci.yml](../.github/workflows/ci.yml)); выкладка – [pages.yml](../.github/workflows/pages.yml): после зелёного CI
на main – сборка того же коммита с адресом `/KinoCompass/` и GitHub Pages.

Графики ECharts грузятся отдельным куском (≈ 205 КБ сжатыми) только на страницах с графиками; основной
кусок – ≈ 39 КБ. Высоту графику задаёт обёртка: собственный стиль vue-echarts (`height: 100%`) сильнее классов
Tailwind 4 в слое utilities.
